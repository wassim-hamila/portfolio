# Mon Portfolio - React

Portfolio personnel réalisé avec React (Vite) et React Router pour le challenge "React Components".

## Pages

- Accueil : présentation (nom, bio, photo)
- Projets : 3 projets avec description et lien GitHub
- Compétences : classées par catégorie (front-end, back-end, outils)
- Contact : formulaire (nom, email, message) avec validation

## Lancer le projet

```bash
npm install
npm run dev
```

## Structure

```
src/
  assets/       images
  components/   Navbar, Footer, ProjectCard
  pages/        Home, Projects, Skills, Contact
  styles/       fichiers CSS
  data.js       infos du portfolio
```
